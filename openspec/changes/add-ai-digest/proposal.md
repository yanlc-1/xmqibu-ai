# Change: 启步 AI 资讯与开源周榜
## Why
将域名验证旧站转为面向中文 AI 爱好者、开发者的响应式资讯站。用户已授权规划后实施，要求 MySQL 和北京时间每日12:00采集。
## What Changes
- 独立 MySQL 数据库保存文章、来源证据、按日项目周增量快照和采集记录。
- 国内外新闻按当天北京时间筛选；多来源覆盖和时效排名，明确并非全网热度。
- GitHub Trending 周榜及语言榜候选按可核验 weekly stars 降序，明确为已采集候选范围，不将总Star冒充周增量。
- 文章详细中文介绍、分类、来源链接，响应式搜索筛选、详情与历史归档。
- Codex 每日12:00整理后通过SSH发布；静态页面通过版本目录原子切换，采集失败不覆盖旧页面。
## Impact
新建独立项目 /opt/www/xmqibu-ai；服务器独立目录 /www/xmqibu-ai 与独立数据库容器；备份旧 /www/xmqibu 后修改此域名入口。考勤项目不变。
