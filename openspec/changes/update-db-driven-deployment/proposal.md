# Change: 本地入库与数据库驱动页面

## Why
用户希望采集在本地完成并直接写入 MySQL，线上只负责读取展示；代码上线方式与 attendance 一致。现有流程将 bundle 上传到服务器，由短时 PHP 容器入库并生成静态文件，数据库位于独立且未开放端口的容器。

## What Changes
- 在 attendance 所在 MySQL 实例新建 `xmqibu_ai` 库，迁移已有内容，分别建立最小权限写入与只读账号。
- 本地通过 SSH 隧道连接数据库，完成校验、历史去重和事务写入；线上 PHP 页面使用只读账号按请求查询，不生成静态 release。
- 构建包含站点代码的 Web 镜像，使用 GitHub 主分支、服务器拉取、构建、容器切换和回滚的发布方式；保留旧静态站用于切换失败时回退。
- 将 `fast-xml-parser` 升级到已修复版本并验证 RSS 解析及依赖审计。

## Impact
影响采集读历史、内容发布、数据库访问、页面运行时、生产发布和回滚。原 AI MySQL 容器与旧静态页面保留至数据和线上验证完成，不影响 attendance 的数据库表或容器。
